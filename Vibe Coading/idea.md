# 💡 Project Idea — Generative AI Web Application

## Project Name
Generative AI Chat Application (React + .NET Core + Azure OpenAI)

## Summary
Build a full-stack Generative AI web application where users interact with an AI assistant using a clean React UI.  
The backend is a .NET Core Web API that connects to Azure OpenAI, processes prompts, and returns structured responses.

## Goal
Create a **production-ready**, scalable AI app using GitHub Copilot’s full workflow:
Idea → Plan → Build → Deploy.

## Key Features
- Real-time AI chat interface  
- .NET Web API for request handling  
- Azure OpenAI for AI model responses  
- React UI with chat components  
- Structured backend services + DI  
- Support for future extensions (RAG, embeddings, search)

## Users
- Developers learning GenAI  
- Business users using AI assistants  
- Students experimenting with AI  
- Teams evaluating Azure OpenAI

## Why This Project?
This project teaches:
- End-to-end generative AI integration  
- Full-stack architecture  
- Using GitHub Copilot Vibe Coding  
- Using Agent Mode and Model Mode  
- Deploying to Azure with CI/CD
